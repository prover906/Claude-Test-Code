Variables store data so you can use it later.

```python
city = "Mumbai"
population = 20_000_000
area_km2 = 603.4
is_capital = False
```

## Built-in data types

| Type | Example | Description |
| --- | --- | --- |
| `int` | `42` | Whole numbers |
| `float` | `3.14` | Decimal numbers |
| `str` | `"hello"` | Text |
| `bool` | `True` | True or False |
| `list` | `[1, 2, 3]` | Ordered, changeable |
| `tuple` | `(1, 2)` | Ordered, unchangeable |
| `dict` | `{"a": 1}` | Key–value pairs |
| `set` | `{1, 2}` | Unique items |
| `NoneType` | `None` | No value |

## Multiple assignment

```python
x, y, z = 1, 2, 3
a = b = 0
x, y = y, x   # swap values
```

## Type conversion

```python
int("10")      # 10
float(5)       # 5.0
str(3.5)       # "3.5"
bool(0)        # False
list("abc")    # ['a', 'b', 'c']
```
