**HTML** (HyperText Markup Language) describes the structure of a web page. It uses *elements* written as tags to label pieces of content: "this is a heading", "this is a paragraph", "this is a link".

```html
<h1>My Website</h1>
<p>Welcome to my corner of the internet.</p>
<a href="https://example.com">Visit example.com</a>
```

## Elements and tags

Most elements have an opening tag, content, and a closing tag:

```html
<p>This is a paragraph.</p>
```

Some elements are *void* and have no closing tag:

```html
<img src="cat.jpg" alt="A sleeping cat">
<br>
```

## Attributes

Attributes add extra information inside the opening tag:

```html
<a href="/about" title="About us">About</a>
```

HTML is not a programming language — it's a **markup** language. It doesn't have logic; it describes content.
