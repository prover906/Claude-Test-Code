## Headings

HTML has six heading levels. Use them in order to create an outline:

```html
<h1>Main title</h1>
<h2>Section</h2>
<h3>Sub-section</h3>
```

Use only **one `<h1>`** per page.

## Paragraphs and line breaks

```html
<p>Paragraphs are separated by space.</p>
<p>Line one<br>Line two</p>
```

## Text formatting

```html
<strong>Important</strong>
<em>Emphasised</em>
<mark>Highlighted</mark>
<code>console.log()</code>
<kbd>Ctrl</kbd> + <kbd>C</kbd>
H<sub>2</sub>O and x<sup>2</sup>
```

## Quotes

```html
<blockquote>
  Talk is cheap. Show me the code.
</blockquote>
```
