## Lists

```html
<!-- Unordered -->
<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>

<!-- Ordered -->
<ol>
  <li>Install VS Code</li>
  <li>Create index.html</li>
</ol>
```

## Tables

Use tables for tabular data, not for layout.

```html
<table>
  <thead>
    <tr>
      <th>Language</th>
      <th>Year</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Python</td>
      <td>1991</td>
    </tr>
    <tr>
      <td>JavaScript</td>
      <td>1995</td>
    </tr>
  </tbody>
</table>
```

Which renders as:

| Language | Year |
| --- | --- |
| Python | 1991 |
| JavaScript | 1995 |
