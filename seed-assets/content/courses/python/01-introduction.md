## Welcome to the course! 👋

In this first lesson we install Python and make sure everything works.

### Why Python?

- It reads almost like English, so you can focus on *ideas* instead of syntax.
- It is used for web development, automation, data science and AI.
- It has a huge community, so help is always one search away.

### Installing Python

1. Go to [python.org/downloads](https://www.python.org/downloads/) and download the latest version.
2. **Windows:** tick *"Add python.exe to PATH"* before clicking *Install Now*.
3. Open a terminal and check the installation:

```bash
python --version
# Python 3.13.0
```

> On macOS and Linux the command may be `python3` instead of `python`.

### Pick an editor

We recommend [VS Code](https://code.visualstudio.com/) with the official **Python** extension. It gives you syntax highlighting, autocomplete and a *Run* button.

Now create a file called `hello.py`, type the line below and run it:

```python
print("Hello, World!")
```

If you see `Hello, World!` in the terminal, you are ready for the next lesson.
