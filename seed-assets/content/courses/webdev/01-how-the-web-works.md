## How the web works

When you type a URL and press Enter, a lot happens in under a second:

1. **DNS lookup** — the browser turns `example.com` into an IP address.
2. **Request** — it sends an HTTP request to that server.
3. **Response** — the server replies with HTML.
4. **Rendering** — the browser reads the HTML, downloads CSS, JavaScript and images, and paints the page.

### The three languages of the front end

| Language | Job |
| --- | --- |
| **HTML** | Structure and content |
| **CSS** | Presentation and layout |
| **JavaScript** | Behaviour and interactivity |

In this course we focus on HTML and CSS. All you need is a browser and a code editor such as VS Code.
